Browse, back up and clean CouchDB data from a desktop GUI — or run the same tool headless from the command line.

Download latest View source

What it does

Server & databases

Connect to a CouchDB server, list databases right away, load DB info on demand and check public access.

Documents & users

Work with large Users, Documents and Dbs Info lists in virtualized grids instead of slow scrolling tables.

Maintenance

Save design documents, delete orphaned replica documents and migrate MySQL data into CouchDB.

Log panel

Copy, paste, clear and save the session log from the header buttons or the File and Edit menus.

GUI or CLI

The egui window opens by default. Add --nox 1 to run headless from a shell or cron job.

Rust & portable

Built with Rust, eframe/egui and couch_rs, with release builds for Linux, Windows, macOS and FreeBSD.

Quick start

cargo build --release
./run.sh              # GUI
cargo run -- --nox 1  # CLI

The binary is at target/release/couchy. On first run, Couchy reads ~/config.toml for the CouchDB and MySQL connections.
